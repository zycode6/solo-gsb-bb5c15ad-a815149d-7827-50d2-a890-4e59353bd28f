# 播客章节标注工作台 (Podcast Chapter Studio)

基于 **React + TypeScript + Web Audio API** 的网页播客章节标注工具：导入本地音频后，在可缩放波形上拖拽创建、移动、调整章节区间，自动吸附邻近边界并阻止重叠，支持键盘微调、章节搜索/排序、选中片段实时预览，并导出带章节标题的 **WebVTT** 和 **JSON** 文件。所有章节编辑（创建、移动、缩放、重命名、删除以及「应用全部候选」）均记录为**可撤销 / 重做**的可逆操作，工具条按钮与 `Ctrl/Cmd+Z`、`Ctrl/Cmd+Shift+Z` 快捷键均可使用，撤销 / 重做不影响当前播放状态。内置**静音切分建议**：按 100ms 窗口分析多声道 RMS，自动在静音中点给出候选切分边界，可一键应用。另内置**章节音量一致性质检**：按 200ms 窗口计算多声道合并 dBFS，以窗口与章节的实际重叠时长加权汇总每章平均音量与动态范围，可自定义过轻 / 过响阈值，异常区间在波形上着色、点击即可从该处预览，并随 JSON 一并导出。支持**章节淡入淡出试听**：每章可独立设置 0～5 秒的淡入 / 淡出时长与开关，预览时按实际播放区间构建增益包络，淡入从静音平滑升至原音量、淡出在章尾前降至静音。新增**连锁移动模式**：可锁定任意章节，拖动或缩放未锁定章节时把边界位移刚性传递给后方未锁定章节，保持间隔与时长不变，遇到锁定章节或音频边界自动限制在可行范围并给出原因提示，绝不重叠；一次拖拽连同其连带变更只是一个撤销步骤。锁定状态仅保留在当前会话，不写入任何导出文件。

## 一键启动（Docker）

前置条件：已安装 Docker（含 Compose 插件，Docker Desktop 自带）。无需在本机安装 Node.js。

```bash
docker compose up --build
```

启动后访问：**http://localhost:8080**（宿主机端口 `8080` → 容器内 nginx `80`）。

修改宿主机映射端口（例如改用 9090）：

```bash
WEB_PORT=9090 docker compose up --build
```

或直接编辑 `docker-compose.yml` 中 `"8080:80"` 的左侧端口。纯静态页面，数据与音频均不出本机、不落盘到容器。

> 不使用 Compose 也可以：`docker build -t chapter-studio . && docker run -p 8080:80 chapter-studio`（自定义端口同理替换 `-p` 左侧数字）。

## 本地开发

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # 章节吸附/防重叠 + 连锁移动/锁定 + 撤销/重做历史 + 静音切分 + 音量质检 + 淡入淡出包络核心逻辑测试
npm run build      # 产出 dist/
```

## 功能与操作

- **导入音频**：点击「导入音频」或把音频文件拖入页面（MP3 / WAV / M4A / OGG 等浏览器可解码格式）。
- **波形缩放**：鼠标滚轮（以光标为锚点）或工具条滑块。
- **创建章节**：在波形空白处按下并拖出一个区间。
- **移动章节**：拖拽章节主体。
- **调整边界**：拖拽章节左右边缘（高亮手柄）。
- **吸附与防重叠**：拖动或调整时，边界在约 10px 内自动吸附到相邻章节边界或文件首尾；所有操作都被钳制在相邻章节之间，不会产生重叠。
- **锁定与连锁移动**：
  - **锁定章节**：点击章节列表项上的 🔓、或在右侧「选中章节」详情中点击锁定按钮即可锁定 / 解锁；波形上锁定章节以琥珀色描边、顶部色条与「🔒 锁定」徽标标识，列表项显示「🔒 锁定」胶囊。锁定章节不可拖动 / 缩放 / 删除（会提示先解锁），但仍可选中、重命名、试听。
  - **连锁移动模式**：波形上方工具条勾选「连锁移动」（或再次勾选关闭）。开启后拖动一个未锁定章节：该章与其后**连续的未锁定章节**组成刚性车队整体平移，章间间隔与各章时长保持不变；向后方第一个锁定章节（或音频结尾）方向移动时，整次操作被限制在刚好不碰撞的范围，波形以青色高亮整列车队、红色虚线标出阻挡边界，工具条实时显示「连锁预览摘要」（带动章节数、位移量、受限原因）。
  - **连锁缩放终点**：在连锁模式下拖动某章的右边缘，本章时长改变，位移同样传递给后方连续的未锁定章节（它们整体平移、时长不变、间隔不变）；拖动左边缘只改本章起点，后方不动（终点未动，无位移可传递）。
  - **限制与提示**：向后移动受前一章（锁定章节 / 音频开头）约束，缩放受 0.2s 最短时长约束；任何受限操作都在工具条与短暂浮条中说明原因（锁定章节名 / 音频边界 / 相邻章节 / 最短时长），并保证**不产生重叠、不越出音频**。
  - **撤销 / 重做**：一次拖拽 / 缩放以及它带动的全部章节变更整体记录为**同一个历史步骤**（合并键仍为该手势），撤销 / 重做完整恢复所有连带章节；键盘方向键微调在连锁模式下同样连锁、且每次按键合并为一个步骤。
  - **会话内有效**：锁定集合与连锁开关仅保存在页面内存中，刷新页面或导入新音频即清空（开关保留用户偏好），`Chapter` 数据结构、WebVTT / JSON 导出格式均不变。
- **撤销 / 重做**：章节创建、移动、缩放、重命名、删除以及「应用全部候选」均为可逆步骤；工具条「↶ 撤销 / ↷ 重做」按钮或 `Ctrl/Cmd+Z`、`Ctrl/Cmd+Shift+Z` 触发。一次连续拖拽、按住方向键微调或在标题框连续输入只算一个历史步骤；任何新编辑都会清空重做栈（分支即失效），撤销 / 重做只回退章节数据，**不改变当前播放 / 暂停状态与播放头位置**；导入新音频时历史随章节一并重置。
- **跳转**：单击波形空白处移动播放头。
- **静音切分建议**：右侧面板调节「静音阈值」（-70 ~ -20 dB）与「最短静音」（0.2 ~ 3s），候选边界以橙色虚线旗标实时预览在波形上；候选只落在未被章节覆盖的空白区间，且自动过滤会产生短于 0.2s 章节的边界。点击「应用全部候选」即在空白区间批量生成章节，已有章节保持不变、结果不重叠。
- **章节音量一致性质检**：导入时复用同一份已解码 PCM，按 **200ms 窗口**计算多声道合并 dBFS（仅扫描一次）。右侧面板可设置「过轻阈值」（默认 -30 dBFS）与「过响阈值」（默认 -6 dBFS，两阈值始终保持至少 1 dB 间隔）。
  - 每章按窗口与章节的**实际重叠时长加权**汇总：能量加权平均 dBFS、min/max 与动态范围；全静音章节均值显示 -∞、状态为「过轻（全静音）」，极短 / 零长度章节标记为「过短」，跨章节窗口按重叠拆分归属，绝不产生 NaN 或错误归属。
  - 波形上以**黄色（过轻）/ 粉色（过响）**色块标出连续异常区间（数字静音按过轻处理，底部有实心状态条）；**单击异常色块即从该处开始预览**，拖拽空白照常创建章节。
  - 章节列表每项显示状态徽标（正常 / 过轻 / 过响 / 过短 + 均值），点击徽标从该章首个异常窗口预览；选中章节的详情区显示均值、动态范围与 min/max，并有「从异常处预览」按钮。
  - 调整阈值只对缓存的窗口 dBFS 重新判定，**不会重新解码或重新扫描音频**。
- **搜索 / 排序**：左侧面板按标题搜索，可按开始时间、标题或时长排序。
- **预览**：列表项 ▶、「预览章节」按钮或快捷键 `P` 播放选中章节区间（到点自动停止）。
- **淡入淡出试听**：选中章节后，在右侧详情区开启「预览该章时应用淡入淡出」，分别设置淡入 / 淡出时长（0～5 秒，步进 0.1s）。
  - 预览该章（含「从异常处预览」）时按**实际播放区间**构建增益包络：淡入从静音线性升至原音量，保持后在章尾前线性降至静音，曲线连续、不越过章界。
  - 淡入 + 淡出超过章节长度时，按两者之和**等比例压缩**到刚好铺满整章；面板实时显示压缩后的实际生效时长。
  - 暂停、拖动播放头、重复预览或修改参数都会先停止旧音源并拆除旧包络再重建，不会叠加残留声音；关闭开关立即恢复原始（无淡入淡出）预览。
  - 淡入淡出设置仅为预览用界面状态，不写入章节数据，WebVTT / JSON 导出格式不变。

### 快捷键

| 按键 | 功能 |
| --- | --- |
| `空格` | 播放 / 暂停 |
| `N` | 在播放头处新建章节（自动寻找空档） |
| `P` | 预览选中章节 |
| `Ctrl`/`Cmd` + `Z` | 撤销上一步章节编辑 |
| `Ctrl`/`Cmd` + `Shift` + `Z` | 重做 |
| `←` / `→` | 移动选中章节 ±0.05s（加 `Shift` 为 ±1s） |
| `Alt` + `←` / `→` | 微调选中章节起点 |
| `Ctrl` + `←` / `→` | 微调选中章节终点 |
| `Delete` / `Backspace` | 删除选中章节 |
| `Esc` | 取消选中 |

### 导出

- **WebVTT**（`*.vtt`）：标准 `WEBVTT`  cues，按开始时间排序，章节标题作为 cue 文本。
- **JSON**（`*.chapters.json`）：`{ version, qualityControl, chapters: [...] }`，时间单位为秒。已导入音频时顶层附带质检参数 `qualityControl: { windowSeconds: 0.2, quietThresholdDb, loudThresholdDb }`，每章附带 `qualityControl`：

```json
{
  "status": "ok | quiet | loud | unknown",
  "meanDbfs": -14.3,
  "minDbfs": -40.0,
  "maxDbfs": -5.0,
  "dynamicRangeDb": 35.0,
  "allSilent": false,
  "silentCoverage": 0.1,
  "quietSeconds": 0.4,
  "loudSeconds": 0.2,
  "analyzedSeconds": 12.3
}
```

全静音章节的 `meanDbfs/minDbfs/maxDbfs` 输出为 `null`（不会输出 `NaN` 或 `Infinity`）。

## 技术要点

- 波形为自绘 Canvas：解码后预计算 200 peaks/s 的 min/max 峰值，任意缩放级别下按像素列聚合渲染，长音频也流畅。
- 静音分析复用已解码的 `AudioBuffer`（不重新解码）：100ms 窗口多声道合并 RMS 只在导入时计算一次；阈值 / 最短静音变化时仅重算静音段与候选边界（`src/audio/silence.ts` 纯函数，由 `scripts/test-silence.ts` 覆盖）。
- 音量质检同样复用导入时已解码的 PCM：200ms 窗口的多声道合并 dBFS 只在导入时计算一次；阈值变化仅对缓存数组重新分类与合并异常区间。章节均值采用能量（重叠时长）加权平均 `10·log10(Σwᵢ10^(dbᵢ/10)/Σwᵢ)`，跨章节窗口按实际重叠拆分归属；静音映射为 `-Infinity`（绝不出 NaN），全静音 / 极短章节均有确定结果（`src/audio/loudness.ts` 纯函数，由 `scripts/test-loudness.ts` 覆盖）。
- 吸附 / 防重叠逻辑集中在 `src/utils/chapterOps.ts` 纯函数中（`moveChapter` / `resizeChapter` / `createChapterInGap` / `findFreeGap`），由 `scripts/test-chapterOps.ts` 覆盖。
- 连锁移动为同一模块中的纯函数（`chainMoveChapter` / `chainResizeChapter` / `chainOutcomeText`）：以「操作章 + 后续连续未锁定章」为刚性车队，按阻挡锁定章 / 音频边界求可行位移区间并整体钳制，吸附只针对车队外的固定边界，返回结构化的 `ChainOutcome`（带动章节、实际 / 期望位移、阻挡类型与阻挡章 id），由 `scripts/test-chainOps.ts` 覆盖（含不重叠 / 不越界不变量扫描）。锁定集合与连锁开关是 `useChapters` 内的会话 UI 状态（不进历史、不进导出、随导入重置），手势合并仍复用历史栈的 `mergeKey`，故一次连锁拖拽天然只有一个撤销步骤。
- 撤销 / 重做为快照式历史栈（`src/utils/history.ts` 纯函数：`record` / `undo` / `redo`）：每条记录保存变更前后的章节数组，新记录即清空重做栈，同 `mergeKey` 且在 800ms 合并窗口内的连续编辑（拖拽、键盘连按、标题连续输入）合并为单步，栈深上限 200；由 `scripts/test-history.ts` 覆盖。历史状态保存在 `useChapters` 的 ref 中（提交时同步镜像章节数据，避免在 React state updater 内产生副作用），导入新音频调用 `reset()` 一并清空，撤销 / 重做不触碰播放引擎。
- 淡入淡出包络为纯函数（`src/audio/fade.ts`：`fitFadeTimes` 等比例压缩、`buildFadeCurve` 生成曲线关键点），由 `scripts/test-fade.ts` 覆盖；播放时 `AudioEngine` 为每次预览挂一个独立的 `GainNode` 包络（source → envelope → 主增益），停止 / 重建时取消自动化并断开节点，杜绝残留声音。
- 播放基于 Web Audio API：`AudioBufferSourceNode` 支持带结束点的片段预览，播放头由 rAF 驱动。
- Docker 为多阶段构建：`node:20-alpine` 构建 → `nginx:1.27-alpine` 托管静态文件。

## 目录结构

```
├── Dockerfile              # 多阶段构建（build → nginx）
├── docker-compose.yml      # 单服务，8080:80
├── nginx.conf              # SPA 回退 + 静态资源缓存
├── src/
│   ├── audio/              # AudioEngine（播放/片段预览/淡入淡出包络）、fade（包络曲线）、peaks（波形峰值）、silence（静音 RMS/候选边界）、loudness（200ms dBFS/章节质检）
│   ├── components/         # Waveform / ChapterList / ChainBar（连锁工具条与预览摘要）/ TransportBar / SilencePanel / LoudnessPanel / FadePanel
│   ├── hooks/useChapters.ts  # 章节增删改 + 撤销/重做历史 + 会话内锁定/连锁模式（reset 随导入清空）
│   ├── utils/chapterOps.ts # 吸附、防重叠、空档查找、连锁移动/缩放与限制原因（纯函数）
│   ├── utils/history.ts    # 撤销/重做快照栈、连续编辑合并、重做栈清空（纯函数）
│   └── utils/export.ts     # WebVTT / JSON（含章节质检指标）导出
└── scripts/                # test-chapterOps、test-chainOps、test-history、test-silence、test-loudness、test-fade
```
